先记住这一句

这个 AI 做的事只有一件：猜错了就改一点点，改到全对为止。像调淋浴水温——太冷往热拧一点，太热往冷拧一点，直到刚好。没有人告诉它「OR 门的规则」，它是自己从 4 道例题里试出来的。

  • 四个点是 4 道例题：蓝点标准答案是 1，琥珀点标准答案是 0。
  • 整片浅色是模型当前认为该判 1 还是判 0 的地盘；红线是两片地盘的分界。
  • 训练过程其实就是这条红线在一点点挪位置，直到把点分对。
  • 柱状图每根柱子 = 一轮里「改了几次参数」，降到 0 就是学会了。

建议按这个顺序点一遍

  1. 保持 OR，点「自动播放」：看红线怎样挪到 x1 + x2 = 1。
  2. 点「重置」再点几次「单步」：看它每次只改很小一点，不是一步到位。
  3. 切到 XOR，点「跑完」：柱子永远不归零——它学不会。
  4. 回 OR，把速度调慢再自动播放，对照右侧日志里每次权重的变化。

为什么 XOR 学不会

OR、AND 的点能用一条直线分开；XOR 的 0 和 1 交叉分布像棋盘格，直线怎么摆都会切错。单层感知机只会画直线，所以永远学不会。这正是后来人们加「隐藏层」的原因——多层才能画出弯的边界。

算法：z = w·x + b，ŷ = 1 if z ≥ 0 else 0； 预测错误时按 w ← w + η·d·x、b ← b + η·d 修正，其中 d = y − ŷ、学习率 η = 0.1。 单步 = 处理一个样本；本轮全部样本无修正即收敛。
OR / AND 线性可分，误差会在有限轮内归零； XOR 线性不可分，任何直线都无法分开四类点，误差持续振荡、永不归零——这正是单层感知机的能力边界。 快捷键：空格 = 单步。

常见疑问

Q：它是不是把 4 道题背下来了？
不是。程序里用训练集之外的点做了推断，它靠学到的红线判断，而不是查表。这正是「学习」和「背诵」的区别。

Q：为什么一开始全猜错？
初始权重是 0，等于完全没想法。它从零开始试错，这反而说明规则是学出来的。

Q：改了 4 轮才算学会，是不是很笨？
这里只有 4 道题、2 个参数，4 轮已经很快了。真实模型有几十亿个参数、海量数据，靠的是同样的「猜错就改」原理，只是放大了规模。

Q：公式看不懂怎么办？
先只盯两样东西：红线怎么动、柱子有没有降到 0。理解这两点，再回来看公式就容易了。
