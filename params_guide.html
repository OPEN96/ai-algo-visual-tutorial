一句话总纲：参数就是模型身上「可以拧的旋钮」。但旋钮分两种 —— 一种是模型自己从数据里拧出来的（叫参数 / 权重），另一种是你开工前先拧好、之后不再动的（叫超参数）。训练这件事，本质上只做一件事：不断微调前一类，直到猜对为止。
LEVEL 0

先分清两类参数

这一步比记任何名词都重要
① 学出来的参数（权重 w、偏置 b）

像做菜时盐放了多少。一开始随便给个值，尝一口（发现太淡）就加一点，再尝再加，最后定下来。这个最终数值不是人规定的，是「尝」出来的。

对应到代码：w 从 [0, 0] 变成 [0.1, 0.1]，这一步发生在训练过程里。

② 人先定好的超参数（学习率、轮数、维度…）

像火候档位、最多尝几次。开工前你自己定，训练过程中不再改。它不直接决定答案，但决定了「学得快不快、稳不稳、能学多复杂」。

对应到代码：lr=0.1、max_epochs=100、DIM=8。

还有第三类容易被误当成参数：只读的结果（误差曲线、注意力百分比、输出向量）。它们是模型算完后给你的「体检报告」，只能看，不能拧。本页每张卡片右上角都标了类别，速查表也按这三类分开。

用 3 行代码看懂「训练」到底改了什么

猜一下 → 和答案比一比 → 猜错就把 w 挪一点点 猜一下 → 和答案比一比 → 猜错就把 w 挪一点点 …… 直到一整轮都没猜错，停下来

这三行里，只有 w 和 b 在变；lr、epochs 自始至终没动过。把这一点记住，后面所有名词都不会混。

LEVEL 1

感知机：最小的模型，参数也最少

对应 perceptron.py / perceptron_visual.html

它做的判断只有一步：x1×w1 + x2×w2 + b ≥ 0 → 判 1。就这 3 个可学的数（w1、w2、b），加上几个你设定的旋钮，构成了全部内容。先按下面的顺序读，前 5 张读完就能看懂整张图。

LEVEL 1.5

两个页面上那些「看起来像参数」的东西

专门给入门者排雷
你看到的东西它其实是什么会影响模型吗
OR / AND / XOR 切换换一套题目（训练数据），不是旋钮会。换题就是换任务，XOR 根本学不会
播放速度 40–600 ms纯动画速度，单位是毫秒完全不会。只影响你看得快不快
单步 / 自动播放 / 跑完 / 重置播放器按钮不会改变计算结果，只控制播放进度
每轮修正次数、累计更新次数训练日志（体检报告）只读，不能调
决策边界 x1 + x2 = 1训练算出来的结论是结果，不是能设定的参数
新样本 [0.5, 0.8]考模型的课外题不参与训练，只用来检验有没有真学会
自注意力页：句子 / Head / 矩阵视图切换选择查看哪一份计算结果。切 Head 会换用另一套打分矩阵，属于「换个模型看」显示内容会变；公式与训练逻辑不变
点击热力图格子（query / activeHead）只决定右侧弧线与明细展示「哪一个词」完全不会影响矩阵数值

判断口诀：训练过程中会被自动改写的，才是参数；开工前你手动填的，是超参数；算完打印出来的，是结果。

LEVEL 2

自注意力：参数变多，但道理没变

对应 attention.py / attention_visual.html

LEVEL 5

常见误区与本例的边界

读完这节，就不会把演示当成真实大模型

Q：把学习率调大，模型是不是就学得更快？
不一定，而且在本例的感知机里完全没有影响：η 从 0.01 调到 2.0，都是 4 轮收敛、误差序列都是 [2,2,1,0]，w 和 b 只是等比例放大，红线位置一模一样。原因是感知机只看「加权求和是正还是负」，整体乘一个正数不改变正负号。到了梯度下降类模型，η 才真正决定成败（见实验 A′）。

Q：权重 w 是不是越大越好？
不是。w 只有和 b、输入 x 放在一起才有意义，衡量的是「相对比例」。w=[0.1,0.1], b=−0.1 与 w=[1,1], b=−1 画出的是同一条线。

Q：温度 τ 是一个真实模型里也有的参数吗？
标准注意力的缩放是固定的 1/√d_k，没有独立温度项；τ 常见于文本生成的采样（0.6–1.0）、知识蒸馏等场景。本页和自注意力页加它是为了教学观察，已在页面标注「1.0 才是标准值」。

Q：自注意力页里那些漂亮的语义关联，是模型自己学出来的吗？
不是。8 维词向量、打分矩阵 M 的规则权重（1.0–3.0）、位置先验都是手工设定的，用来模拟「训练完成后」的样子。勾选「随机权重」看到的均匀颜色，才是未训练状态。真实模型里这些矩阵由海量数据学出，人并读不懂每一维的含义。

Q：这些就是完整 Transformer 的全部参数了吗？
不是。真实模型还包含 W_O 多头拼接投影、残差连接、LayerNorm、前馈网络 FFN、词表嵌入、位置编码（RoPE / ALiBi），以及训练侧的优化器、权重衰减、dropout（注意力上常取 0.1）、warmup 与学习率调度、batch size 等。本例是单层自注意力的前向计算，用于理解核心运算，规模与完整模型不可同日而语。

Q：完全记不住怎么办？
只需记住三个：w/b 是学出来的答案，lr/epochs/DIM 是你先定好的旋钮，A/O/误差曲线是算完的结果。其余遇到时回查第 4 节速查表即可。
