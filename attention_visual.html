先记住这一句

把句子里每个词想成开会的人。自注意力就是：每个人都环顾一圈，决定「我该听谁的、听多少」，再把别人的话按比例记进自己的笔记。没有人事先写规则，只有互相打分。

这张图怎么看

  • 热力图一行 = 一个词在「看」别人；列 = 被看的词。颜色越深，看得越多。
  • 每行加起来正好 100%，表示这个词的「注意力总量」被分配完了。
  • 点任意一格，右边弧线会变粗变细——线越粗，那个词贡献越大。
  • 「分数 QKᵀ」是原始打分，「logits」是缩放后，「注意力 A」是换成百分比的最终结果。

建议按这个顺序点一遍

  1. 默认「指代」句，看「它」那一行：它同时看「猫」和「老鼠」。
  2. 切到 Head 2：变成主要关心附近的词，说明不同头分工不同。
  3. 打开因果掩码：右上半变灰，这就是 GPT 不能偷看后面的词。
  4. 勾选随机权重：颜色变均匀，说明语义是训练出来的，不是架构自带的。
  5. 温度拖到 2.0（变平均），再拖到 0.3（只剩一两个深色格）。

术语白话对照

token
切好的词，例如「猫」「它」。
词嵌入 X
给每个词贴 8 个特征标签（是不是实体、是不是动作…），用数字记下来。
Q 查询
「我想找什么样的信息」——我提的问题。
K 键
「我能提供什么信息」——挂在每个人胸前的标签。
V 值
「我实际要说的内容」——最后被抄进笔记的东西。
点积 QKᵀ
拿我的问题去和每个人的标签比对，越匹配分数越高。
√8 / 温度
两个旋钮，防止分数太大或太小；温度低 = 更偏心，温度高 = 更平均。
softmax
把一堆分数改写成加起来正好 100% 的百分比。
因果掩码
不许看后面的词，像写作文不能抄自己还没写的下一句。
多头
同时开几场会，每场关注不同关系（一个看语义，一个看相邻）。
输出 O
每个词更新后的「笔记」= 别人信息的加权混合。

和前面的感知机什么关系

感知机是一个神经元，用一条直线把点分成两类；自注意力是让词与词互相打分，再重新组合信息。共同点只有一个，却最关键：参数由数据改出来，而不是人写死规则。

前向计算流程与矩阵从左到右就是一次计算的六个步骤

X (n×8)→ Q = X·W_Q→ K = X·W_K→ S = QKᵀ/√8→ A = softmax→ O = A·V
低 中 高 行 = query，列 = key；每行和为 1

选中 token 的注意力去向线越粗 = 看得越多

该行的逐步计算分数 → 缩放 → 变成百分比

输出向量 O[query]（8 维语义特征）这个词更新后的「新笔记」

公式：Q=X·W_Q、K=X·W_K、V=X·W_V； S=QKᵀ/√8；A=row_softmax(S/τ + 位置先验)；O=A·V。 本演示取 W_K=W_V=I、W_Q=M，故 QKᵀ = X·M·Xᵀ，M 为非对称双线性打分矩阵（等价于真实模型中学得的 W_Q·W_Kᵀ）。
与真实模型的差异（请明确）：8 维词嵌入、打分矩阵 M 与位置先验均为手工设定，用于呈现可解释的「训练后」模式，并非真实训练所得；勾选「随机权重」可对比未训练时接近均匀的注意力。 温度默认 0.6 用于放大低维嵌入下的差异，τ=1.0 才是标准缩放。 完整 Transformer 还包含多头拼接后的 W_O 投影、残差连接、LayerNorm 与前馈网络，此处均未包含。
读图要点：Head 1 呈现代词/动词/修饰语对实体的远程关注，Head 2 呈局部带状关注——两者关注模式不同，正是多头注意力的意义。因果掩码开启后上三角被屏蔽，即 GPT 类解码器「只能看已生成的 token」。

常见疑问（先看这几条，公式可以最后再看）

Q：颜色深，是不是代表模型「认为」两个词有关？
不能这么理解。它只表示在这一层、这个注意力头里，这个词分到的权重高。权重不是因果解释，也不是置信度。

Q：为什么每行都一定要凑够 100%？
因为 softmax 把分数归一化成了比例。它是「注意力预算怎么分」，不是「每个词有多重要」的绝对分数——某个词权重低，也可能只是被别的词挤掉了。

Q：这些数字是真实大模型算出来的吗？
不是。这里的 8 维词向量和打分规则是手工设计的，目的是让你看清结构。勾选「随机权重」就能看到未训练时的样子；真实模型的规律是从海量数据里学出来的。

Q：完全看不懂公式怎么办？
先只做三件事：看「注意力 A」热力图的深浅、点格子看右边弧线的粗细、切换 Head 1 / Head 2 比较差异。这三步不需要任何数学，理解之后再看公式会容易很多。
